# Week 5 - Password Generator & Your Own Module

## Description

This project demonstrates how to use Python built-in modules and how to create and import a custom Python module.

## Files

- `password_generator.py` - Generates a password using random, string, and math modules.
- `helpers.py` - Contains my own custom functions.
- `main.py` - Imports and uses the two modules.

## Concepts Practiced

- Importing Python modules
- Using the random module
- Using the string module
- Using the math module
- Creating functions with default values
- Creating a custom module
- Importing a custom module

## How to Run

```bash
python main.py
